📊 Employee Attrition Analysis | Power BI

Turning Workforce Data into Actionable HR Insights

📌 Project Overview

Employee attrition is an important workforce challenge that can affect organizational stability, productivity, and employee retention. This project uses Microsoft Power BI to explore employee attrition patterns and identify workforce characteristics associated with employees leaving an organization.

The dashboard transforms employee data into interactive visual insights, helping users explore attrition across job roles, job levels, job satisfaction, work-life balance, age groups, and other workforce dimensions.

🎯 Project Objectives

- Analyze employee attrition patterns across different workforce categories.
- Explore the relationship between job satisfaction, work-life balance, and employee turnover.
- Compare attrition across job levels, job roles, and demographic groups.
- Build an interactive, multi-page dashboard for exploring HR data.
- Present workforce insights through clear and meaningful visualizations.

🛠️ Tools & Technologies

- Microsoft Power BI Desktop — Dashboard development and data visualization
- Power Query — Data preparation and transformation
- DAX — Measures and calculations
- Data Visualization — KPI cards, charts, matrix visuals, and interactive slicers

📈 Dashboard Highlights

1. Workforce Overview

- Total employee count
- Employees who left the organization
- Employee attrition rate
- Average employee age
- Employees remaining in the organization

2. Attrition Analysis

- Attrition across departments and job roles
- Employee departures by job level
- Attrition patterns across demographic groups
- Job satisfaction and work-life balance analysis

3. Interactive Exploration

- Department, gender, and overtime slicers

💡 Key Analytical Focus

This project explores questions such as:

- Which departments and job roles account for the most employee departures?
- How does attrition vary across job levels and age groups?
- What patterns can be observed across job satisfaction and work-life balance categories?
- How can interactive dashboards help HR teams investigate workforce trends?

Note: Employee departure counts and attrition rates measure different things. Counts identify where departures are concentrated, while rates compare departures with the total employee population in each group.
